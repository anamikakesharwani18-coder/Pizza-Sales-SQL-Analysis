# Pizza Sales Analysis using PostgreSQL

## Project Overview
This project focuses on analysing pizza sales data using PostgreSQL to identify sales trends, customer ordering patterns, and revenue performance.

## Tools Used
- PostgreSQL
- pgAdmin

## Database Tables
- Orders
- Order Details
- Pizzas
- Pizza Types

## SQL Concepts Used
- SELECT and WHERE
- Aggregate Functions
- JOINs
- GROUP BY and HAVING
- ORDER BY and LIMIT
- Common Table Expressions (CTEs)
- Window Functions

## Business Questions
1. What is the total number of orders?
2. What is the total quantity of pizzas sold?
3. Which pizza category generates the highest revenue?
4. Which pizza types are the best sellers?
5. Which pizza size generates the highest revenue?
6. What is the average order value?
7. Which day and hour have the highest sales?

## Key Findings
- Total Orders: 21,350
- Total Pizzas Sold: 495,174
- Average Order Value: Approximately 38.31
